# 🌦️ Weather App

A simple and responsive weather application that shows the current weather of any city using the Open-Meteo API.

## 🚀 Live Demo

https://vishal400402-create.github.io/WEATHER-APP/

## 📌 Features

- 🔍 Search weather by city name
- ⌨️ Search using Enter key
- 🌡️ Current temperature
- 💧 Humidity information
- 💨 Wind speed
- 🌤️ Weather condition and icons
- 📍 Get weather using current location
- ⏳ Loading state
- ❌ Error handling
- 💾 Save last searched city using LocalStorage
- 📱 Responsive design for mobile devices

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Open-Meteo API
- LocalStorage
- Git & GitHub
- GitHub Pages

## 🌐 API

Weather data is provided by the Open-Meteo API.

No API key is required.
